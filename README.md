# 猜数字小游戏（Guess the Number）

一个用 **Python** 编写的命令行小游戏：电脑随机想一个 1~100 的整数，你来猜，
程序会提示「大了」或「小了」，直到猜中为止，并统计你一共猜了几次。

本项目是**通识课程任务**的练习作品，主要目的是熟悉
「写代码 → 命令行运行 → 用 Git 管理 → 推送到 GitHub」这一整套基本开发流程。

---

## 一、游戏玩法

1. 程序启动后，电脑在 **1 到 100** 之间随机想好一个整数
2. 你在命令行里输入你猜的数字，然后按回车
3. 程序告诉你结果：
   - 猜的数 **比答案大** → 提示「大了，往小一点猜」
   - 猜的数 **比答案小** → 提示「小了，往大一点猜」
   - 猜的数 **正好等于答案** → 恭喜猜中，游戏结束
4. 游戏结束时，程序会告诉你 **总共猜了几次**

> 小技巧：用「二分法」猜得最快。先猜 50，根据提示把范围砍掉一半，
> 再猜中间值……理论上最多 7 次就一定能猜中（因为 2⁷ = 128 > 100）。

## 二、运行方法

### 环境要求

| 项目 | 要求 |
| --- | --- |
| 操作系统 | Windows |
| Python | 3.6 或更高版本（本项目在 Python 3.13.15 上测试通过） |
| 依赖库 | 无。只用到 Python 自带的 `random` 模块 |

检查 Python 是否安装成功：

```cmd
python --version
```

如果能看到类似 `Python 3.13.15` 的输出，说明环境没问题。

### 运行步骤

1. 按 **`Win + R`**，输入 `cmd`，回车，打开命令提示符
2. 用 `cd` 命令进入本项目的文件夹（`/d` 参数用于跨盘符切换）：

   ```cmd
   cd /d D:\play_do\first
   ```

3. 运行程序：

   ```cmd
   python guess_number.py
   ```

4. 按照屏幕提示输入数字即可开始游戏。想中途退出，按 `Ctrl + C`。

## 四、程序逻辑说明

整个程序只有 **一个文件**，逻辑分成三块：

### 第 1 步：电脑想一个数字

```python
import random
answer = random.randint(1, 100)
```

`random` 是 Python 自带的随机数模块。`randint(1, 100)` 会随机返回一个
1 到 100 之间的整数（包含 1 和 100 本身），把它存进变量 `answer`。

### 第 2 步：用 `while` 循环反复让玩家猜

```python
count = 0
while True:
    text = input("请输入你猜的数字（1-100）：")
    ...
```

- `count` 是**计数器**，一开始是 0，玩家每猜一次就加 1
- `while True` 表示「条件永远成立」，会**一直循环**下去，
  直到程序执行到 `break` 才会跳出来

### 第 3 步：判断输入是否合法，再比较大小

```python
if not text.strip().isdigit():
    print(">> 输入无效，请输入一个整数，例如 42")
    continue

guess = int(text)
count = count + 1

if guess > answer:
    print(">> 大了，往小一点猜")
elif guess < answer:
    print(">> 小了，往大一点猜")
else:
    print(f"恭喜你，猜对了！答案就是 {answer}")
    print(f"你一共猜了 {count} 次。")
    break
```

这里有三处值得注意的地方：

| 代码 | 作用 | 为什么需要 |
| --- | --- | --- |
| `text.strip().isdigit()` | 判断输入是不是纯数字 | `input()` 拿到的**永远是字符串**。如果玩家输入 `abc`，直接 `int()` 转换会让程序崩溃，所以要先检查 |
| `continue` | 跳过本轮剩下的代码，重新问一次 | 输入错了不该算作一次猜测，也不该中断游戏 |
| `break` | 跳出循环，结束游戏 | 猜中了自然就不需要再问了 |

`f"..."` 叫做 **f-string**，是 Python 3.6 之后推荐的字符串格式化写法，
大括号 `{}` 里可以直接写变量名，会被替换成变量的值。

## 六、常见问题

**Q：提示 `'python' 不是内部或外部命令`？**
说明 Python 没有加入系统环境变量 PATH，或者安装时没勾选
「Add Python to PATH」。请重新安装并勾选该选项，或手动把 Python 的安装目录
添加到 PATH。

**Q：提示 `python` 打开了微软应用商店？**
这是 Windows 的「应用执行别名」在捣乱 —— 系统里有个假的 `python.exe` 占位符
指向应用商店。解决办法：设置 → 应用 → 高级应用设置 → 应用执行别名，
把 `python.exe` 和 `python3.exe` 两项关掉。

**Q：输入中文标点的数字（比如 `５０`）会怎样？**
会被判定为「输入无效」，因为 `isdigit()` 只认半角数字。请用英文输入法输入。

## 附录：关于 Markdown 和 README

> 这部分是任务要求「自学 md 文件用途和使用方法」的学习记录。

**Markdown 是什么？**
Markdown 是一种**轻量级标记语言**，用几个简单符号就能写出带格式的文档，
纯文本就能读，转成网页也好看。它最常见的用途就是写项目说明文档。

**README 有什么作用？**
`README.md` 是一个项目的「门面」和「说明书」。别人（包括几个月后的你自己）
打开这个仓库，第一眼看到的就是它，用来快速了解：这个项目是干什么的、
怎么跑起来、代码怎么组织的。

在 GitHub 上，如果仓库根目录里有 `README.md`，它的内容会**自动显示在仓库首页**，
这也是它这么重要的原因。

**本项目用到的 Markdown 语法：**

| 语法 | 写法 | 效果 |
| --- | --- | --- |
| 标题 | `# 一级` `## 二级` | 分级标题 |
| 加粗 | `**粗体**` | **粗体** |

| 代码块 | 用三个反引号包起来，后面可标语言 | 高亮代码 |
| 行内代码 | `` `代码` `` | `代码` |

| 引用 | `> 文字` | 引用块 |
| 链接 | `[文字](网址)` | 超链接 |
